# 对话替换单个景点

在结果页的「每日行程」点击「对话换景点」，或在旅行助手中说明天数、原景点和想去的类型。助手先展示附近候选，用户确认后才替换；支持撤销最近一次对话修改。手动编辑中需先保存或取消。

## 附近检索

- 结合原景点和当天前后相邻景点作为搜索中心，以当日城市限定高德周边搜索。优先 5 公里，候选不足时扩大至 10 公里并提示。每个中心每个半径最多搜索 2 页，每页 25 条，最多返回 3 个候选。
- 排除无效坐标、跨城、重复、越界及出入口等附属设施。优先共同覆盖区域，再考虑相邻路段直线距离增量和距原景点距离。
- 距离是直线估算，不能视为实际交通时长或路费。室内条件按场所类别保守筛选，开放时间、预约和具体展区仍须核实。
- 模型只提取意图及目标，候选来自地图接口。认证失败和无结果分别提示，不生成虚构地点兜底。

## 修改与预算

只替换一个景点，更新当天摘要、地图坐标、图谱与门票预算。酒店、餐饮、交通估算保持原值。新景点游览时长沿用原安排，确认卡会提示。

高德 `biz_ext.cost` 是人均消费，不能当门票。无法核实门票时使用 `null`，显示「待核实」及「已知费用小计」。设定门票硬上限时，未知价格的候选不能直接应用。整天重排、住宿调整和全日预算等暂返回澄清提示。

候选使用服务器保存的随机令牌，10 分钟有效；确认时校验行程版本与候选 ID，防止旧建议覆盖新修改。结果保存于当前浏览器会话，原始历史计划不覆盖。撤销记录仅在当前页面内保留。
